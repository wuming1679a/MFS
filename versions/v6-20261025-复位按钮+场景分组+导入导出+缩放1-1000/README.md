# v6 — 复位按钮 + 场景分组/导入导出 + 缩放 1%~1000%

日期：2026-10-25　基于 v5

## 本次变更

1. **右上角最右侧新增「复位」按钮**
   从右往左的次序变成：`复位 → 主题 → 场景`（`#resetBtn` 固定在 `right:12px`，不参与拖动）。
   点一下 = 一次把"看的方式"复位，画的内容不动：
   - 视图缩放回 100%、平移回原点（`resetView()`）
   - 四个面板清掉内联 `left/top/right/bottom` 与 `data-dragged`，并全部展开
   - 主题按钮清掉 `localStorage['simThemePos']`，回到默认右上角（`right:56px`）
   - 图标做一次 ↺ 回弹动画；键盘 `R` 同效
   实现：`js/panels.js` 的 `resetAllLayout()`。

2. **场景可存数量 12 → 200**
   `SCENE_MAX = 200`（`js/scene.js`）。超了自动 pop 最旧的（列表新的在前）。
   200 个场景 ≈ 几百 KB，仍在 localStorage 5MB 配额内；写失败会提示"存储不可用或已满"。

3. **场景分组（教学用）**
   - 记录结构变成 `{ name, group, at, data }`，`group` 缺省落到「未分组」
   - 保存行变成三件套：`分组（作业1）` + `场景名（第二题）` + `保存`；分组输入带 `datalist`，用过的组名可下拉选
   - 列表按组渲染：组头 = 折叠箭头 + 组名 + 条数徽标 + 「导出整组」「删除整组」
   - 折叠状态记在内存（`collapsedGroups`），本次会话内有效
   - **同名/同组才覆盖**：「作业1 / 场景1（第二题）」和「作业2 / 场景1（第二题）」是两条
   - 自动命名也按组查重，不会和别的组撞名
   - 载入某个场景后，分组输入框自动填上它所属的组，方便"改完再存回同组"

4. **导出 / 导入场景**
   - 对话框工具条：`导出全部` `导入`，右侧显示 `N / 200`
   - 每条场景、每个组也各有一个 ↓ 导出按钮
   - 导出格式：
     ```json
     { "app": "charge-sim-scenes", "v": 1, "exportedAt": 1690000000000,
       "scenes": [ { "name": "场景1（第二题）", "group": "作业1", "at": 0, "data": { ... } } ] }
     ```
     文件名：`场景-全部-20261025.json` / `场景-作业1-20261025.json`
   - 导入：接受上面这种对象，也接受裸数组；同组同名覆盖、其余新增；坏条目跳过并报数
   - 文件读取用 `FileReader` + `Blob` 下载，全程本地，不需要联网

5. **「反射间隔」= 发射器的发射间隔，改成三级 + 滑动条一块**
   原来分成「发射间隔（稀/中/密）」和「间隔数值（滑条）」两行，现在是同一个带边框的块：
   上面三级预设、下面滑条，标签行右侧显示当前值（`0.150 s`）。
   - 双向同步：点预设 → 滑条跟着走；拖滑条 → 预设高亮跟着走
   - 跳到非预设值 → 预设全灭 + 亮出「自定义」角标
   - 滑条步长取 `0.001`，预设值（0.05 / 0.15 / 0.4）能被精确命中，不会出现"点「密」滑条停在 0.04874"
   - 全部就地更新，不重建面板，拖滑条不会打断手感

6. **视图缩放范围 25%~420% → 1%~1000%**
   `SCALE_MIN = 1, SCALE_MAX = 1000`（`js/core.js`，`SCALE` 的数值本身就是百分比）。
   缩放读数低于 10% 时显示一位小数（`3.4%`），否则取整 —— 1% 附近一步就是几倍，取整会"跳着走"。
   网格的步长自适应逻辑原本就有上下夹逼，1% / 1000% 下都不会出现线糊成一片。
