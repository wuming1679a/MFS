# MFS · 场与带电粒子模拟编辑器

一个纯前端的电场 / 磁场与带电粒子可视化编辑器：在画布上摆放场、负场、障碍和发射器，
实时观察带电粒子在洛伦兹力下的运动轨迹，支持场景保存、分组、导入导出，方便课堂演示与作业分发。

**在线使用：<https://wuming1679a.github.io/MFS/>**

无需安装、无需构建、没有后端 —— 双击 `index.html` 即可运行，也可直接部署为静态站点。

## 功能

### 组件

| 类别 | 内容 |
| --- | --- |
| **场** | 单边界、双边界、单边界有限场、双边界有限场、扇形场、三角形场、矩形场、圆形场、椭圆形场、无限场 |
| **负场** | 同上，用于局部抵消 / 挖空已有场 |
| **障碍** | 线形障碍（可设为实体，粒子无法穿越） |
| **发射器** | 点发射器、不同角度发射器、不同速度发射器、线状发射器 |

- 场分 **电场 E** / **磁场 B** 两种：电场给恒定方向与强度，磁场按 `bDir` 决定垂直纸面向内 / 向外。
- 场的边界可设为 `开放` / `实体`：实体边界会挡住粒子。
- 发射器可调发射间隔（稀 / 中 / 密三级 + 滑条微调）、初速度、角度、电荷量、质量、轨迹样式与颜色。

### 交互

- 画布滚轮缩放（**1% ~ 1000%**）、空白处拖动平移、`Shift` 框选。
- 磁性吸附 / 严格网格吸附双模式；拖动时给出**组件边界对齐参考线**。
- 多选后整组拖动，统一偏移；`Esc` 在拖动中按下可回滚。
- 属性面板随选中项切换，面板可折叠、可拖动。

### 场景管理

- 场景保存 / 加载（本机 `localStorage`，上限 **200** 条）。
- **分组**：如 `作业1 / 场景1（第二题）`，同组同名才算覆盖，跨组同名互不影响。
- **导出 / 导入 JSON**：可导出全部、导出整组、导出单条；导入时同组同名覆盖、其余新增、坏条目跳过并报数。课堂上分发与收作业直接传文件即可，不走网络。

### 界面

- 明暗双主题，切换按钮可拖动并记忆位置；亮色主题使用深色光标。
- 右上角「复位」一键恢复视图与面板布局（不动画布内容）。
- 组件库、分段控件、开关、滑条、提示条等均使用 [Oat UI](https://oat.ink/) 语义化组件；图标动效来自 [Morphicons](https://www.morphicons.com/)。
- 所有依赖已本地化到 `vendor/`，**零外部网络请求**。

## 实现要点

- **粒子用 SoA**：`PS{x,y,vx,vy,qm,...}` 一组平行 TypedArray，推进循环内零对象分配。
- **轨迹用环形缓冲**：一整块 `Float32Array` 定长环形写入，写入 O(1)；粒子多时按预算自动缩短轨迹长度。
- **Boris 半隐式积分**：子步长 0.8 ms，子步数有上限，负载过高时放大步长而不是丢时间。
- **批绘**：粒子按 `调色板索引 × 轨迹模式` 分桶，描边次数从上万降到几十。
- **背景图层缓存**：`sceneHash()` 命中时只 `drawImage`，不重画网格与场。
- **Oat UI 的 `@layer` 特性**：组件样式都在层里，项目自己的无层 CSS 天然优先级更高，定制无需 `!important`。
